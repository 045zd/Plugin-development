# 学习通作业截止提醒（Edge 扩展）

一个**只做提醒**的 Edge 扩展：监控学习通网页版课程**作业**与**考试**的截止时间，临近截止时用  
**浏览器通知 + 邮件**提醒你，并支持学习通登录页**账号自动填充**。

> ⚠️ 合规边界（本项目的设计前提）
>
> - **不自动答题、不自动提交作业**——用搜题插件代做并提交作业属于学术不端，本项目不提供；
> - **不保存密码、不自动登录**——扩展只保存账号（可选），密码交给 Edge 自带的密码管理器；
> - **不操作你正在使用的标签页**——采集在后台隐藏标签页中完成。
>
> 本项目仅在你**已经登录**学习通网页版的浏览器会话里读取作业/考试列表，用于计算截止时间。

---

## 环境要求

| 组件                      | 要求                         |
| ----------------------- | -------------------------- |
| Microsoft Edge          | Chromium 126+（Manifest V3），Edge 130+ 均可 |
| Python（仅邮件代理需要）          | 3.10+，且已加入 PATH 或能用 `pythonw` 启动 |
| Node.js                 | 不需要（仅开发期跑测试用）              |

> 邮件代理只使用 Python 标准库，无需 `pip install` 任何依赖。  
> 双击 `mail-proxy/start.bat` 即可启动。

## 功能一览

| 功能      | 说明                                             |
| ------- | ---------------------------------------------- |
| 截止监控    | 定时（默认每 60 分钟）扫描全部课程的作业与考试，计算剩余时间               |
| 临近提醒    | 默认在剩余 72 / 24 / 6 / 1 小时各提醒一次（阈值可配置），过期再提醒一次   |
| 浏览器通知   | 点击通知直接打开对应学习通页面                                |
| 邮件提醒    | 通过本机 Python SMTP 代理发送，支持 QQ/163/Outlook 等邮箱授权码 |
| 登录失效提醒  | 学习通会话失效时，浏览器通知 + 邮件提醒你重新登录                     |
| 账号自动填充  | 登录页自动填入账号（密码由 Edge 密码管理器负责）                    |
| 插件失联提醒  | 代理超过 3 小时收不到扩展心跳时，发邮件提醒"插件可能没有运行"              |
| 课表课程过滤  | 上传本学期课表（Excel/CSV），只监控课表里的课程，过滤历史学期已结束的课程      |
| 大学搜题酱联动 | 跳转到作答页后自动点击其「AI 会话」按钮（可在设置页关闭）                 |
| 实验报告检查  | 检查已提交的实验报告是否空白、栏目是否完整、课程名称是否匹配                 |
| 互评任务      | 将「待互评 / 未互评 / 互评中」作为待办显示并参与提醒，`已互评` 才算完成      |

## 安装扩展（Edge）

1. 打开 Edge，地址栏输入 `edge://extensions/`；
2. 打开右下角/左侧的 **开发人员模式**；
3. 点击 **加载解压缩的扩展**，选择本项目的 `extension` 目录（即含 `manifest.json` 的那一层）；
4. 安装后会自动打开设置页（若没有，点扩展图标 → 齿轮/设置）。

> 本扩展是 Manifest V3，Edge 130+ 均受支持。

## 首次配置

### 1. 登录学习通

在 Edge 中打开 <https://passport2.chaoxing.com/login> 登录一次学习通网页版。  
扩展复用这个登录状态，**不会保存你的密码**。

### 2. 监控设置

设置页 →「监控设置」：

- 检查间隔：默认 60 分钟（15~720）；
- 监控范围：作业 / 考试（可分别开关）；
- 单次最多检查课程数：默认 15。

### 3. 邮件通知（可选但推荐）

浏览器扩展**无法直接连 SMTP 服务器**，所以邮件通过一个本机 Python 代理发送：

1. 打开 `mail-proxy/` 目录，按其中 `README.md` 配置 `config.json`（邮箱 SMTP 授权码、收件人）；
2. 双击 `start.bat` 启动代理（或按 README 设置开机自启）；
3. 在扩展设置页填写代理地址（默认 `http://127.0.0.1:8765`），打开「邮件通知」；
4. 点「发送测试邮件」验证。

### 课表课程过滤（推荐，v1.2.0+）

学习通课程列表会包含历史学期的课程（例如上学期已结束的课），它们的作业/考试可能造成干扰。  
设置页 →「课表课程过滤」：

1. 点「上传课表文件」，选择本学期课表（支持 `.xlsx` 或 `.csv`，也可把 Excel 另存为 CSV）；
2. 插件本地解析（内置零依赖解析器，**文件不会上传到任何服务器**），列出识别到的候选课程；
3. 勾选本学期课程（可「全选/全不选」，也可手动补充课程名）；
4. 打开「只监控课表内的课程」开关，点「保存设置」。

开启后，扫描结果只保留课表里的课程；课程名无法确定的条目（例如部分考试）会自动保留，避免漏提醒。

### 4. 登录页自动填充（可选）

设置页 →「登录填充」：

- 勾选「自动填充账号」，填入你的学习通账号（手机号/超星号）；
- **密码不会保存**：第一次登录时在 Edge 弹出的"保存密码"提示中点击保存，  
  之后 Edge 会自动填充密码（这是浏览器能力，比把密码交给扩展安全）。
- 扩展只会在学习通登录页生效，不会在其它网页填写。

## 使用

点击 Edge 工具栏的扩展图标：

- 顶部显示登录状态与上次检查时间；
- 主列表只显示**未截止**的待办，按截止时间排序，颜色从灰 → 黄 → 橙 → 红表示紧迫程度；
- 已截止且未提交的条目（含聚合页不再显示剩余时间、截止时间未知的）**默认完全隐藏**；
  如需回顾漏交项，可在 设置 →「监控设置」开启「显示已截止/时间未知的未交项」，
  它们会收在底部折叠分组里；  
  作业若重新开放，下一次扫描会重新放回主待办；
- 点 **立即检查** 手动刷新（首次扫描需要逐门课程采集，约 1~2 分钟，进度会显示在弹窗里）；
- **点击整条卡片**（或右侧「打开」按钮）直接跳到学习通对应的**作答页**：  
  优先打开**电脑版**作答页（`mooc-ans/mooc2/work/dowork`，考试为电脑版 `examnotes`），  
  兼容「大学搜题酱」等第三方插件；电脑版解析失败时回退手机版 `doHomeWork` / `doExam`；  
  两者都失败则停留在详情页。首次打开需要多走几步页面跳转，约 3~6 秒。
- **大学搜题酱联动**：若已安装「大学搜题酱」，跳转到作答页后会自动点击它的「AI 会话」悬浮按钮；  
  可在 设置 →「监控设置」关闭「自动打开大学搜题酱 AI 会话」。未安装时静默跳过。

### 实验报告检查

设置页 →「实验报告检查」→「开始检查」：

- 只检查标题含「实验」且**已提交**（待批阅/已完成等）的作业；
- **默认跳过已过截止时间的作业**（那类条目没有可检查的提交内容，勾选「包含已过截止时间的作业」可强制检查）；
- 对每份报告打开电脑版只读详情，读取附件和文本答案；
- **支持正文解析的格式**：Word `.docx`、Word 97 `.doc`（OLE2 复合文档）、PDF；
  解析器为内置零依赖实现，按文件魔数判断真实格式（不依赖学习通给出的 filetype）；
- 检查「实验内容和步骤」「实验结果及分析」等栏目是否为空（自动剔除下划线、点线等占位符）、
  报告里填写的课程名称是否与条目课程一致；
- 结果逐条显示「正常 / 需人工确认 / 疑似有问题」，并给出附件名、类型、大小、正文提取字数与原因。

> 检查在后台隐藏标签页进行，通常需要几十秒；检查期间会暂停定时扫描。  
> 图片、压缩包等无法解析正文的附件会标为「需人工确认」，不会误判为有问题。

## 首次验证清单

加载扩展后按顺序确认：

1. 打开 `edge://extensions/`，「学习通截止提醒」没有红色「错误」按钮；
2. 点工具栏扩展图标，弹窗能正常打开（首次可能显示「状态未知」），无报错；
3. 在 Edge 登录一次 <https://passport2.chaoxing.com/login>，回到弹窗点「立即检查」；
4. 等 1~2 分钟（弹窗顶部显示采集进度），列表出现作业/考试即采集成功；
5. 设置页 →「发送测试邮件」，收件箱收到测试邮件；
6. 持续运行观察：截止时间临近时收到浏览器通知/邮件，点击通知能打开学习通页面。

> 首次安装后约 8 秒会自动在后台检查一次；浏览器每次启动也会自动检查。  
> 采集在后台隐藏标签页中完成，不会跳转你正在使用的页面。

## 工作原理（简述）

1. 定时创建/复用一个**非激活（后台）标签页**；
2. **优先读取移动版聚合页**（一次拿到全部课程的作业/考试，通常几秒完成）：
   - 作业：`https://mooc1-api.chaoxing.com/work/stu-work`（页面 `ul.nav > li` 结构）
   - 考试：`https://mooc1-api.chaoxing.com/exam-ans/exam/phone/examcode`（页面 `ul.ks_list > li` 结构）
   - 状态取自页面**专门的状态元素**（状态文本 + 状态 class 标记），而不是对整块文本做关键词猜测，  
     因此"已完成/已交/待批阅/待互评"能准确识别，不会再混进/漏掉待办列表；
3. 若聚合页不可用（学习通改版、网络问题），自动**回退到逐课程采集**：  
   课程列表接口 → 每门课进入课程页 → 点「作业/考试」标签 → 解析列表 iframe；
4. 若启用了「课表课程过滤」，只保留课表内课程的条目（课程名无法确定的条目保留），  
   `scanMeta` 记录过滤数量；
5. 计算剩余时间，按阈值发送通知/邮件（同一作业同一阈值只提醒一次）；
6. 全部结束后关闭后台标签页。

> 学习通没有公开的"列出全部作业"JSON 接口，以上都依赖页面结构。  
> 如果某次学习通改版导致解析为空，更新 `extension/background/parser.js` 中的选择器即可。

## 更新记录

- **v1.2.25**（当前，修复两条自相矛盾的检查结论）：
  - **症状**：同一条检查结果会同时显示「未识别到标准实验栏目，正文有内容，建议人工确认」
    和「与教师模板的栏目结构一致（3/4 栏）」——一句说没识别到栏目，一句说栏目对得上。
  - **真因**：两处用了不同严格度的正则。模板比对用宽松匹配（v1.2.24 新增），
    正文分析仍用严格匹配。报告是表格，转纯文本后栏目名与内容直接相接
    （`实验目的1.掌握…`），严格正则只切得到「成绩和评语/指导教师/审阅日期」这类固定表格项，
    它们不在 CONTENT_HEADINGS 里 → `presentContent` 为空 → 误入「未识别到实验栏目」分支。
  - **修复**：新增 `templateCovered`（模板可用且覆盖率 ≥60%）。命中时该分支不再说
    「未识别到栏目」，改用总正文字数判定：<80 字判「模板的栏目结构能对上，但正文几乎没有内容」（bad），
    <200 字判「正文内容较少」（warn），再往上保持 ok。没有模板时旧行为完全不变。
  - 补 4 项测试覆盖：严格匹配全落空时不报矛盾结论、正文极少判 bad、正文偏少判 warn、
    无模板时旧提示保留。测试总数 146 → 161。
- **v1.2.24**（用教师模板判断报告内容是否相符）：
  - **为什么要模板**：判断「你交的报告是不是这次实验的」，从前靠的是标题字符串相似度。
    可标题写法太自由（自己起名、写「实验X：xxx」、只写「实验二」），
    人工智能实验二那条误报就是这么来的：报告里写「聚类算法实现」，
    作业标题是「人工智能实验报告-实验2-2026」，字面几乎没重合，但报告确实是对的。
  - **模板才是可靠依据**：教师给的模板（题目区附件的那份 docx）里栏目是固定的，
    你填的报告必然沿用同一套骨架。标题能被改写，骨架很难整体换掉。
    现在会从题目区附件里挑出模板（能识别出 ≥2 个实验栏目、且是 doc/docx/pdf 的才算），
    提取栏目骨架，再和你的报告逐栏比对覆盖率。
  - **覆盖率 ≥60%**：判定「与教师模板的栏目结构一致」，并**压制标题不符的提示**——
    结构对得上就说明交对了，标题怎么措辞都不影响。
  - **覆盖率 <40% 且模板栏目 ≥3**：才提示「与教师模板的栏目结构差异较大」，
    并列出模板里有、你报告里缺的栏目名。判级刻意保守，宁可少报也不冤枉人。
  - **教师预填的标题是权威标题**：模板里「实验名称」栏若已被教师写死（如「实验2 PCA降维」），
    会作为 templateTitle 单独取出，比你自己写的那份更贴近实验本身。
  - 检查结果里新增 **「模板核对：N/M 栏」**，以及可展开的 **「教师模板栏目（N）」**——
    逐栏列出模板骨架，你报告里没找到的栏目会标注「（你的报告里没找到）」。
  - 技术上补了一个必须点：报告和模板都是**表格**，转纯文本后栏目名与内容直接相接
    （学号：姓名：实验名称聚类算法实现实验目的1.掌握…），原来的严格正则
    （标题后须是冒号/空白）一栏都匹配不到。新增宽松版正则专门用于**读模板骨架**
    和判断栏目存在性；报告正文切分仍用严格版，避免正文误切。
- **v1.2.23**（修复同名附件被覆盖 + 作答区在富文本编辑框内）：
  - **根因一：同名文件被去重合并**。题目区的模板和你提交的报告**文件名完全相同**
    （都叫「2.降维-机器学习实验报告.docx」，仅大小不同：23.18K vs 82.29K）。
    去重键用的是文件名，两条被并成一条，且保留了题目区那条 → 永远"只找到题目区材料"。
    现在去重键优先用 objectid，同名不同文件不再互相覆盖。
  - **根因二：区域判定只扫一趟**。真实页面整个题目（题干 + 作答编辑器）都包在
    .TiMu / .questionLi 里，从附件往上找第一个命中的容器必然是题目区。
    现在改**两趟扫描**：先找作答区/编辑器容器，找不到才认题目区。
  - **根因三：作答区在富文本编辑框的 iframe 里**，且是 javascript:void(...) 异步
    document.write 写入的，遍历时节点还没出现。现在补了空帧重试（最多 3 轮 × 350ms），
    并把 edui/ueditor/ans-editor/ans-attach-ct/ans-insertfile/froala 等编辑器类名纳入作答区识别。
  - **兜底：同名文件按大小择优**。空白模板不可能比成品大——即使区域判定全失败
    （两边都 unknown），也把同名文件中**最大的那份**算作答区，其余算题目区。
- **v1.2.22**（修互评阶段误检 + 采集不到提交附件）：
  - **问题一：互评阶段的作业被当成"还没截止"**。你猜得对。互评阶段聚合页仍显示
    「剩余 6 天 2 小时」，但那是**互评截止时间**，不是提交截止时间——能进入互评
    就说明提交窗口早关了。旧逻辑只看 deadline，于是去检查一份根本不存在的报告，
    得到「只有题目区的教师材料」这种无意义结论。
    现在新增 `isPeerReviewItem()`（状态 / extra / deadlineText 任一含「互评」即命中），
    检查前直接跳过，进度提示也改成「已截止/互评中/截止时间未知」。
  - **问题二：采不到你提交的附件**。实测数据显示，采到的你的附件 `type` 全是空的，
    说明它们是被 HTML 兜底正则捞到的，而不是从 DOM 结构里读到的——**作答区大概率
    在 iframe 里，主文档 querySelectorAll 看不见**。现已改为遍历同源 iframe
    的 `contentDocument`（含嵌套两层），跨域帧会计数但不报错。
  - 文本答案采集同样遍历 iframe（此前 6 条结果 `textAnswerLen` 全为 0 就是这原因）。
  - **只找到题目区材料时不再判 bad，降为 warn**：这说明是我们的采集没命中，
    而不是你的报告有问题，不能反过来冤枉你。
  - 检查结果里新增可展开的「页面结构诊断」：iframe 数量/同源跨域/补采到几个附件、

## 常见问题

**Q：扫描很慢？**  
正常情况走移动版聚合页，几秒内完成。如果弹窗顶部显示「改用逐课程采集」，说明聚合页不可用  
（可能改版或网络问题），此时课程多时需要 1~2 分钟，属正常回退。扫描在后台进行，不影响你使用 Edge。

**Q：显示"未登录"？**  
在 Edge 里重新登录学习通网页版即可，点击弹窗里的「去登录」。

**Q：收不到邮件？**

1. 确认 `mail-proxy` 正在运行；2) 设置页点「发送测试邮件」看错误信息；
2. `mail-proxy/proxy.log` 查看详细日志；4) 检查邮箱授权码是否是"SMTP 授权码"而不是登录密码。

**Q：点「立即检查」后列表一直是空的？**

1. 确认弹窗顶部显示「已登录」（显示未登录就先点「去登录」重新登录学习通）；
2. 打开 `edge://extensions/` → 本扩展「服务工作进程」→ 点「检查视图」打开控制台，  
   看 `[截止提醒] 扫描完成：课程 X 条目 Y` 与「聚合页不可用」相关日志；
3. 若聚合页不可用且回退后仍为空，通常是学习通页面结构有变化，需要更新  
   `extension/background/parser.js` 中的选择器；
4. 把控制台日志（不要含个人信息）反馈给开发者即可定位。

**Q：旧学期已结束的课程总出现？**  
设置页 →「课表课程过滤」上传本学期课表并打开「只监控课表内的课程」，历史课程会被过滤掉（见首次配置）。

**Q：某条作业/考试的状态显示「未知」或不对？**  
打开设置页 →「数据管理」→ 点「复制诊断数据」，把复制的内容发给我（不含账号密码、cookie），  
我可以直接看到该条目的页面结构并修正识别规则。

**Q：为什么找不到"自动答题/自动提交"？**  
本项目不提供此类功能（见开头合规边界）。

**Q：扩展 ID 每次加载会变吗？**  
解压加载的扩展 ID 由路径决定，路径不变 ID 不变。如果更换目录，浏览器可能重新分配 ID。

## 隐私与安全

- 扩展本地存储仅含：配置、作业/考试列表、提醒记录、你主动填写的账号；
- **不存储密码**，密码只保存在 Edge 密码管理器中；
- 邮件代理只监听 `127.0.0.1`，配置（含 SMTP 授权码）只保存在本机 `mail-proxy/config.json`；
- 邮件只发送到你配置的收件人；
- 项目无任何遥测、统计或远程上报。
